EQUATRAN is an equation solver: you type the equations exactly as they are, and the program orders them, picks a convergence scheme and solves. One set of equations serves both the forward and the backward calculation. This course climbs from basic algebraic equations up to PDEs, optimization and parameter regression — every problem a real chemical-engineering one — with a sandbox on the same page so you can run the code as you read it.

1.1

EQUATRAN ต่างจากการเขียนโปรแกรมอย่างไร

How EQUATRAN differs from writing a program

ถ้าเขียนโปรแกรมเอง คุณต้องจัดรูปสมการใหม่ทุกครั้งที่โจทย์เปลี่ยนทิศทาง — EQUATRAN ไม่ต้อง

Write your own program and you must rearrange the algebra every time the question turns around. EQUATRAN never asks you to.

ลองดูสมการ Antoine ตัวเดียว log₁₀P = A − B/(C+t) ถ้าเขียนด้วย Excel หรือภาษาโปรแกรมทั่วไป การคำนวณ “ให้ t หา P” กับ “ให้ P หา t” เป็นคนละโปรแกรม (อันหลังต้องใช้ Solver) แต่ใน EQUATRAN คุณเขียนสมการเดิม แล้วแค่เปลี่ยนว่าตัวไหนคือข้อมูลที่ให้มา

Take one Antoine equation, log₁₀P = A − B/(C+t). In Excel or a general-purpose language, “given t, find P” and “given P, find t” are two different programs — the second one needs Solver. In EQUATRAN you write the same equation and simply change which variable is the given data.

Forward: t → P
//Antoine
log10(PA)=A-B/(C+t)
A=8.08097
B=1582.271
C=239.726
t=50          // t is given
// PA = 416.5845
Backward: P → t
//Antoine
log10(PA)=A-B/(C+t)
A=8.08097
B=1582.271
C=239.726
PA=760        // P is given
// t = 64.5477

สมการบรรทัดเดียวกัน ต่างกันแค่บรรทัดสุดท้าย — นี่คือหัวใจของ equation solver ตัวเลข 416.5845 และ 64.5477 มาจากเอกสาร PreFEED “EQUATRAN 1. Algebraic and Differential Equations” หน้า 35–37

The same equation line, differing only in the last line — that is what an equation solver buys you. The values 416.5845 and 64.5477 come from PreFEED, “EQUATRAN 1. Algebraic and Differential Equations”, pp. 35–37.

The Antoine and Riedel curves for methanol nearly coincide over 0–100 °C, but Riedel carries five parameters (C₁–C₅) against Antoine's three — ease of regression is why Antoine is still everywhere.

Workflow: source text → object → result

Workflow: source text → object → result

EQUATRAN แยกขั้นตอน “compile” (แปลสมการเป็นลำดับการคำนวณ) ออกจาก “go” (คำนวณตัวเลข) เสมอ

EQUATRAN always separates “compile” (turning equations into a calculation order) from “go” (crunching the numbers).

โครงสร้างไฟล์และขั้นตอนการทำงานFile types and the run sequence

Compile + Go รวมกันเรียกว่า “Run” — ถ้ามี error ตอน compile จะไม่มีไฟล์ object เกิดขึ้นเลย

Compile + Go together are called a “Run” — if compilation finds errors, no object file is produced at all.

ตัวตรวจสมดุลสมการ–ตัวแปร (Degrees of Freedom)

Equation–variable balance checker (degrees of freedom)

ก่อนกด Run ทุกครั้ง ให้เช็กว่า “จำนวนสมการ = จำนวนตัวแปรที่ไม่รู้ค่า” — นี่คือ error ที่พบบ่อยที่สุดของผู้เริ่มต้น

Before every Run, check that the number of equations equals the number of unknowns — this is the single most common beginner error.

E − (V − Vi − Vn − Vs) = 0
สัญลักษณ์ความหมายนับอย่างไร
ENumber of equationsอาเรย์นับทีละ element; ไม่นับ # expression
VTotal number of variablesอาเรย์นับทีละ element; y' นับเป็นตัวแปรแยกต่างหาก
ViInput variablesตัวที่ประกาศใน INPUT (ไม่นับ INITIAL)
VnNot-referred variablesประกาศใน VAR แต่ไม่เคยถูกใช้เลย
VsIntegral variablesตัวแปรที่หาค่าจากการอินทิเกรต + ตัวแปรอิสระ; เป็น 0 ถ้าไม่มี INTEGRAL/REPEAT
SymbolMeaningHow it is counted
ENumber of equationsArrays count element by element; # expressions are not counted
VTotal number of variablesArrays element by element; y' counts as its own variable
ViInput variablesThose named in INPUT (INITIAL does not count)
VnNot-referred variablesDeclared in VAR but never used anywhere
VsIntegral variablesVariables obtained by integration plus the independent variable; 0 if there is no INTEGRAL/REPEAT

ค่าที่ได้ = 0 คือ OK · ติดลบ = under specified (สมการน้อยไป) · เป็นบวก = over specified (สมการมากไป)

Zero is OK · negative means under specified (too few equations) · positive means over specified (too many).

วางโปรแกรมของคุณ แล้วให้เครื่องนับให้Paste your program and let it count

เครื่องมือนี้เลียนแบบส่วน “(1) Statistics” และ “(5) validity” ของ diagnostic message จริง แต่เป็นการนับแบบประมาณ — คำตัดสินจริงมาจาก compiler เสมอ ใช้เป็นการตรวจก่อนกด Run เท่านั้น

This mimics the “(1) Statistics” and “(5) validity” blocks of the real diagnostic message, but the count is approximate — the compiler always has the final word. Treat it as a pre-flight check.

ข้อความ error จริงที่คุณจะเห็น

The real error message you will see

(5) validity
    (E)-{(V)-(Vs)-(Vi)-(Vn)} = -1 ... under specified
    Matching information
    tau is under specified
    eq1==> L

อ่านว่า: EQUATRAN จับคู่ (matching) สมการกับตัวแปรแล้ว พบว่าไม่มีสมการเหลือให้คำนวณ tau ส่วนสมการ eq1 ที่มี tau อยู่นั้นถูกจองไปคำนวณ L แล้ว

Read it as: EQUATRAN matched equations to variables and found no equation left to compute tau — equation eq1, which does contain tau, has already been claimed to compute L.

3.1 Newton–Raphson ที่ทำงานอยู่ข้างใน

  
3.1 The Newton–Raphson running underneath

  
EQUATRAN ใช้ modified Newton–Raphson โดยหาอนุพันธ์ด้วยผลต่างจำกัด

  
EQUATRAN uses a modified Newton–Raphson method with a finite-difference derivative.

  
xk+1 = xk − f(xk) / f′(xk)   ,  
    f′(xk) ≈ [f(xk+Δx) − f(xk)] / Δx

  
Δx = min[ (upper − lower)·p , max(0.1p, |x|·p) ]   โดยwith p = 0.001

  
ทำไม [l,h] ถึงสำคัญแม้คำตอบจะอยู่กลางช่วง — เพราะขอบเขตเป็นตัวกำหนดขนาด Δx
  ที่ใช้หาอนุพันธ์ ถ้าตั้งช่วงกว้างเกินไป Δx จะใหญ่จนอนุพันธ์เพี้ยน ถ้าแคบเกินไปก็อาจไม่ครอบคลุมคำตอบ

  
Why [l,h] matters even when the answer sits comfortably inside — the bounds set the
  size of Δx used for the derivative. Too wide and Δx is so large the derivative is meaningless; too narrow and the
  root may fall outside.

// 1. P, t -> x
t=10
output t,x

/*  2. P, x -> t
x=1.4e-5
output t,x    */

/*  3. temperature dependency
repeat t [0,100] step 10
trend x [1e-5,2e-5]   */

    
ผลที่น่าสนใจ โหมดที่ 3 เผยว่าเส้น x(t) มีจุดต่ำสุดราว 50 °C
    (x = 1.3096×10⁻⁵) — แปลว่าโหมดที่ 2 “ให้ x หา t” มี สองคำตอบ
    นี่คือเหตุผลที่ค่าเดาเริ่มต้นและขอบเขตสำคัญ: EQUATRAN จะให้คำตอบที่อยู่ใกล้ค่าเดาของคุณ

    
The interesting result Mode 3 reveals that x(t) has a minimum near 50 °C
    (x = 1.3096×10⁻⁵) — which means mode 2, “given x find t”, has two answers. That is exactly why the initial
    guess and the bounds matter: EQUATRAN returns whichever root lies nearest your guess.
