The big picture

How do we determine a rate expression?

Kinetic parameter estimation · the recipe

Seven moves from experiment to constants

  • Experiment to see which variables move the rate.
  • Fix the mechanism / pathway / steps.
  • Multiphase? First find conditions with no transport effect.
  • Choose the rate-limiting step.
  • Derive the rate expression from that mechanism.
  • Collect data in a well-chosen experimental reactor.
  • Regress the data; if consistent, keep the constants, else loop back.
Every reactor here is isothermal: no energy balance needed.
Apparent rate = measured rate, transport included. 9-8 removes the film, 9-10 the pores.

Experimental reactors · isothermal

Four families of kinetic reactor

1 · Batch

Fluid (& catalyst basket) charged once; sample $C_j(t)$. First choice for kinetics.

2 · Mixed flow (CSTR)

Gradientless / internal-recycle (Berty, Carberry). Steady state at one uniform $C_j$.

3 · Integral tubular

Fixed bed; large conversion along the bed. Mimics the commercial reactor.

4 · Differential tubular

Thin bed; tiny conversion so $C_j\approx$ const → read $-r_j$ directly.

Family 1 · batch reactor

Batch: the kineticist’s first choice

When: first kinetic study — heat- and mass-transfer effects are easy to remove and $T$ easy to hold.
Limits: sample vs total volume, heat-up/cool-down lag, cannot watch deactivation, poor for gas phase, does not mimic a fixed bed.

Family 2 · mixed-flow / gradientless

Mixed flow: one uniform concentration

$$\tau=\frac{V}{v_0}=\frac{V}{F_0}\qquad -r_j=\frac{F_{j0}-F_j}{W}$$
Steady state at constant concentration. Change the flow to vary $\tau$ without disturbing heat/mass transfer.
Limits: time to reach steady state; residence-time distribution; cannot observe deactivation.

Families 3 & 4 · tubular flow

Integral vs differential tubular reactor

Integral (fixed bed)Differential (thin bed)
Conversion across bedlarge, $X$ grows with $W/F_0$small, $\Delta C$ tiny
What you read$F_j$ vs $W/F_{0}$ (integrate)$-r_j$ vs $C_j$ directly
Best forvalidating a model; heat/mass-transfer & deactivationrate that depends strongly on $C_j$
Main limithard to vary $\tau$ cleanly; $T$ distributionneeds high-precision analysis of small $\Delta C$

The whole regression, in twenty lines

EQUATRANOpen EQUATRAN ↗
// A --> B, isothermal batch -- fit k to five samples
GLOBAL n = 5

FUNCTION cal(k, te ; CAc)
  VAR te(n), CAc(n)
//1. model and initial condition
  CA' = -k*CA
  CA # 10
//2. sample the trajectory at the measurement times
  CAc # 0
  CHANGE (CAc # CA) ON (time >= te)
//3. integrate
  INTEGRAL time [0, 11] STEP 0.001
  TREND CA STEP 1
END

//4. main program: data, residual, objective
  VAR te(n), CAe(n), CAc(n), eA(n)
  te  = (2, 4, 6, 8, 10)
  CAe = (7.4, 4.9, 3.8, 2.4, 2.2)
  cal(k, te, CAc)
  eA = CAc - CAe
  FIND (k # 1 [0.001, 10]) LEAST eA
  OUTPUT k, CAc, eA

The three balances, integrated once per trial pair

EQUATRAN · 1 of 2Open EQUATRAN ↗
// A --> B --> C, isothermal batch -- fit k1 and k2
GLOBAL n = 6

FUNCTION react(k1, k2, te ; CAc, CBc, CCc)
  VAR te(n), CAc(n), CBc(n), CCc(n)
//1. the three coupled balances
  CA' = -k1*CA
  CB' =  k1*CA - k2*CB
  CC' =  k2*CB
//2. initial charge
  CA # 1 ; CB # 0 ; CC # 0
  CAc # 0 ; CBc # 0 ; CCc # 0
//3. sample all three species at the same times
  CHANGE (CAc # CA, CBc # CB, CCc # CC) ON (time >= te)
  INTEGRAL time [0, 61] STEP 0.001
  TREND CA, CB, CC STEP 1
END

// GLY + DMC <--> GLC + 2 Me  ;  GLC --> GLD + CO2
GLOBAL n = 11

FUNCTION cal(k1, k2, k3, te ; GLYc, GLCc, Mec)
  VAR te(n), GLYc(n), GLCc(n), Mec(n)
  V = 0.300 ; Mcat = 0.84       //1. reactor: L and g
  cw = Mcat/V                   // g of catalyst per litre
//2. rate laws, per gram of catalyst
  r1 = k1*CGLY*CDMC - k2*CGLC*CMe^2
  r2 = k3*CGLC
//3. balances: dC/dt = (Mcat/V)*(rate per gram)
  CGLY' = -cw*r1
  CDMC' = -cw*r1
  CGLC' =  cw*(r1 - r2)
  CMe'  =  cw*2*r1
  CGLD' =  cw*r2
//4. initial charge
  CGLY # 2.91 ; CDMC # 9.25
  CGLC # 0 ; CMe # 0 ; CGLD # 0
  GLYc # 0 ; GLCc # 0 ; Mec # 0
//5. sample and integrate
  CHANGE (GLYc # CGLY, GLCc # CGLC, Mec # CMe) ON (time >= te)
  INTEGRAL time [0, 481] STEP 0.01
END

The Langmuir–Hinshelwood form

$$-r'_A=\frac{k\,P_A}{1+K_A P_A+K_B P_B}$$
$P_A\!\to\!0:\;-r'_A\approx kP_A/(1{+}K_BP_B)$ — linear, as observed.
$P_A\!\to\!\infty:\;-r'_A\to k/K_A$ — the saturation plateau, 2.01 mol/(g·s).
Ten points, three constants. Both sets are needed: with $P_B=0$ alone, $K_B$ is invisible.

Diagnose before you trust the rate

The stirring test and Mears’ criterion

$$C_M=\frac{-r'_A\,\rho_c\,R\,n}{k_c\,C_{Ab}}<0.15$$
If the inequality holds, the film resistance is negligible: $C_{As}\approx C_{Ab}$.
  • Raise stirring or flow: if the rate still rises, the film limits.
  • Rate independent of agitation → kinetic regime.
  • $r'$ = observed rate per gram, $n$ = order, $R$ = particle radius, $\rho_c$ = particle density, $k_c$ = film coefficient.

// Problem IV: ethanol -> ethyl acetate, Cu/Cu-chromite, 220 C, 20 bar
// (1) E <--> A + H     (2) E + A <--> EA + H     dual site
GLOBAL n = 3

FUNCTION bed(k1, k2, KE, KA, KH, KEA, SVe ; fEc, fAc, fEAc)
  VAR SVe(n), fEc(n), fAc(n), fEAc(n)
//1. fixed operating data
  P    = 20                     // bar
  K1eq = 0.131                  // bar, thermodynamics -- NOT fitted
  K2eq = 60.74                  // -
  fN2  = 0.114                  // mol N2 per mol ethanol fed
//2. partial pressures from the running flows
  fT  = fE + fA + fEA + fH + fN2
  PE  = P*fE/fT
  PA  = P*fA/fT
  PEA = P*fEA/fT
  PH  = P*fH/fT
//3. one denominator, written once and squared
  D = (1 + KE*PE + KA*PA + KH*PH + KEA*PEA)^2
//4. the two surface rates, per gram of catalyst
  r1 = k1*KE*PE*(1 - PA*PH/(K1eq*MAX(PE,1E-12)))/D
  r2 = k2*KE*KA*PE*PA*(1 - PEA*PH/(K2eq*MAX(PE*PA,1E-12)))/D
//5. balances on catalyst weight, per mole of ethanol fed
  fE'  = -r1 - r2
  fA'  =  r1 - r2
  fEA' =  r2
  fH'  =  r1 + r2
  fE # 1 ; fA # 0 ; fEA # 0 ; fH # 0.00754   // H2 carrier in the feed
  fEc # 0 ; fAc # 0 ; fEAc # 0
  CHANGE (fEc # fE, fAc # fA, fEAc # fEA) ON (SV >= SVe)
  INTEGRAL SV [0, 20.1] STEP 0.002
  TREND fE, fA, fEA, fH STEP 1
END
//6. main program: one run, three space velocities (Table 3)

  VAR fEc(n), fAc(n), fEAc(n), xc(n), sac(n), seac(n)
  VAR ex(n), ea(n), eb(n)
  SVe  = (1, 4, 20)                   // g cat h / mol ethanol
  xee  = (0.1369, 0.2496, 0.4669)
  sae  = (0.4295, 0.1806, 0.0563)
  seae = (0.5705, 0.8194, 0.9437)
  bed(k1, k2, KE, KA, KH, KEA, SVe, fEc, fAc, fEAc)
  xc   = 1 - fEc
  sac  = fAc/(fAc + fEAc)
  seac = fEAc/(fAc + fEAc)
  ex = xc - xee ; ea = sac - sae ; eb = seac - seae
  FIND (k1 # 900 [0, 5000], k2 # 13 [0, 500], KE # 1.6 [0, 50], ..
        KA # 0.14 [0, 50], KH # 0.02 [0, 50], KEA # 5.2 [0, 50]) ..
       LEAST (ex, ea, eb)
  OUTPUT k1, k2, KE, KA, KH, KEA, xc, sac, seac

Problem IV · parts (c) and (d)

An equilibrium ceiling, and four constants too many

The bed runs against equilibrium. $K_1K_2$ allows $x_E=0.580$ at infinite catalyst; the last point, 0.4669, is 80 % of that ceiling. That is why conversion flattens while selectivity still climbs.
Reaction 1 alone would stall at $x_E=0.081$: $K_1=0.131$ bar is small. Reaction 2 keeps removing acetaldehyde, so reaction 1 never reaches its own equilibrium — the ester step is what drags the bed forward.
(c) Every starting guess reaches SSE $\approx1.8\times10^{-3}$, with constants spread over an order of magnitude. Drop $K_H$ and $K_{EA}$ altogether and SSE is $2.9\times10^{-3}$ — barely worse. The data do not require the inhibition terms at all.
(d) Move what the reaction cannot: co-feed hydrogen, acetaldehyde or ester; change the pressure; add points between 4 and 20; repeat at a second temperature.
Same lesson as Problem I, now on published data: a good fit is not a measured constant.

Key Takeaways

1

Match reactor to job: batch to start, mixed flow or differential to read a rate, integral bed to validate.

2

Multiple reactions: integrate numerically, minimise SSE over every species, rank mechanisms by SSE.

3

EQUATRAN: a prime is a derivative, # an initial value, FIND … LEAST a regression — never in the same program as INTEGRAL.

4

A good fit does not make every constant real: a constant the data never move is still reported.

5

Remove transport before trusting kinetics: Mears outside, Weisz–Prater and Thiele inside, apparent $E_a$ as the tell. Deactivation needs a flow reactor.
